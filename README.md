**makefun-job-title** is a Python entry for the "Weirdest Job Title: Blind Judge Showdown" bounty on make.fun. It contains a minimal `main.py` that, when run, writes exactly one approved job title to `entry.txt` in the directory named by the `MAKEFUN_OUTPUT_DIR` environment variable (default `/output`).

## Run it

```bash
python3 main.py
```

You can override the output directory with `MAKEFUN_OUTPUT_DIR=/tmp/test python3 main.py`.
